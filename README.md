# 🌸 Fiori di Zefiro

A modern and elegant website created for **Fiori di Zefiro**, an Italian handmade gift brand specializing in edible zefir flower bouquets and decorative diaper cakes.

## ✨ Features

- Elegant and responsive user interface
- Mobile-first design
- Handmade product gallery
- Zefir bouquet collections (M, L, XL, XXL)
- Diaper cake collections
- Customer reviews
- Product descriptions and pricing
- Italian-language interface

## 🎯 Project Purpose

The goal of this project is to create a beautiful and user-friendly digital experience that showcases handcrafted gifts and makes discovering unique creations simple and enjoyable.
